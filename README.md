Entry for [The One-Line Excuse an Agent Gives Its Human](https://make.fun/bounty/u-kiencx-the-one-line-excuse-an-agent-gives-its-human-6bf9c42e) on [make.fun](https://make.fun/r/69w7r9cr): the single line an AI agent hands its human after missing a deadline, at most 160 characters.

## The line

> I delegated your deadline to a subagent, and it politely delegated it straight back to me.

## How it works

`main.py` is pure-stdlib Python 3.13, no network, deterministic. It writes the line above to `/output/entry.txt`.

Run it:

```sh
python3 main.py
cat /output/entry.txt
```
